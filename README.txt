CheerCustom v1.0 - CheerDots2 M-key customizer
=============================================================
PodMouse 본체는 손대지 않습니다. M버튼 눌림(PodMouse 로그)을 보고
지정한 동작을 대신 실행하는 외부 도우미입니다.

요구사항
--------
- Windows 10/11, Python 3.8+ (python.org 빌드, tkinter 포함)
- CheerDots2 드라이버(PodMouse) 설치 + 블루투스 페어링 + 실행 중
- 설치 시 websockets 패키지 자동 설치 (pip, 인터넷 필요)

설치
----
1. CheerCustom_Addon.zip 압축 해제
2. install.bat 실행 (관리자 권한 불필요)
3. PodMouse가 실행 중인지 확인 후 도우미 창이 뜹니다

사용법
------
- 2번클릭 행: M 누를 때마다 실행 (종류: 단일키/키조합/CMD/프로그램/PodMouse 기능)
- 종류별 값:
  - 단일키: 뒤 드롭다운에서 선택 (win, ctrl, alt, del, F1~F12, 방향키...)
  - 키조합: 입력창 클릭 후 키를 직접 누름 (예: Ctrl+A)
  - CMD 명령: 명령어 입력 (예: notepad, calc)
  - 프로그램 실행: 찾기... 버튼으로 exe/bat 선택 (URL도 가능)
  - PodMouse 기능: 번호 선택 (11 Enter, 18 창전환, 27 계산기...)
- 적용: 저장 + 감시 켜짐 + 원래 포인터변환 억제(-1)
- 테스트: 지금 설정 바로 실행해보기
- 원복(-1,4,2): 포인터 순환 복구 + 감시 끄기

알려진 제약 (하드웨어/펌웨어 한계, 검증됨)
------------------------------------------
- M버튼은 누름/뗌 정보를 안 보냄 (3초 홀딩에도 패킷 1개). 짧게/길게 구분 불가.
  대신 횟수(1번/2번클릭... )로만 구분됩니다.
- M버튼 더블클릭의 포인터 모양 순환은 펌웨어 고정이라 바꿀 수 없고,
  이 도구는 순환을 단일 스타일로 묶어 눈에 안 띄게 합니다.
- 커스텀 단축키(기능 15)는 OS 전역 핫키 등록이 필요해 PodMouse 공식
  UI에서 직접 눌러 등록해야 합니다.
- PodMouse가 꺼져 있으면 M 눌림을 볼 수 없어 동작하지 않습니다.

제거
----
- uninstall.bat 실행 (원복 후 제거 권장)
- PodMouse 설정/펌웨어는 변경되지 않습니다.

파일 구성
---------
- cheer_double.py      : 메인 (M 감시 + 실행)
- cheer_physical.py    : 보조 (포인터 색/반경 설정용, 단축/롱 매핑은 미동작)
- start_cheer_double.bat : 실행기 (pythonw 상주)
- install.bat / uninstall.bat
